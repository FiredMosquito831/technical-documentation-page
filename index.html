Introduction

Flexbox is a one-dimensional layout method for arranging items in rows or columns.

Items flex to fill additional space or shrink to fit into smaller spaces.

This documentation explains the core concepts of the CSS Flexbox layout module.

display: flex; display: inline-flex;
  • Understand the flex container and flex items.
  • Learn how alignment and distribution work.
    • Flex Container

    The flex container is the parent element that holds flex items.

    Setting display: flex on an element makes it a flex container.

    Its direct children automatically become flex items.

    flex-direction: row; flex-wrap: wrap;
  • flex-direction controls the main axis direction.
  • flex-wrap controls whether items wrap to new lines.
    • Flex Items

    Flex items are the direct children of a flex container.

    Each item can grow or shrink along the main axis.

    Use the flex shorthand to control item sizing behavior.

    flex: 1; flex-grow: 2;
  • flex-grow defines how much an item can grow.
  • flex-shrink defines how much an item can shrink.
    • Alignment

    Flexbox provides powerful alignment properties.

    justify-content aligns items along the main axis.

    align-items aligns items along the cross axis.

    justify-content: center; align-items: center;
  • justify-content distributes space between items.
  • align-items aligns items vertically in a row.
    • Responsive Design

    Flexbox makes responsive layouts easier to build.

    Combine flexbox with media queries for adaptive designs.

    Items can reflow automatically as the viewport changes.

    flex-direction: column; flex-basis: 100%;
  • Use media queries to change layout at breakpoints.
  • Switch from row to column on small screens.
    • Reference

    All properties referenced here follow the CSS Flexbox specification.

    See the MDN documentation for the complete list of flex properties.

    gap: 10px; order: 1;
  • gap adds spacing between flex items.
  • order changes the visual order of items.
